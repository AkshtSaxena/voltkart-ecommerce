# VoltKart Client

The VoltKart client is a React single-page application built with Vite and Tailwind CSS. It provides the storefront, product pages, cart, checkout, account access, and order history.

For project requirements, environment configuration, and full setup instructions, see the [project README](../README.md).

## Client scripts

- `npm run dev` starts the local development server.
- `npm run build` creates an optimized production build.
- `npm run preview` serves the production build locally.
- `npm run lint` runs ESLint.
